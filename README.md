# Prospector IA

Ferramenta que encontra clientes novos com a ajuda da IA: busca negócios no Google Maps, por
cidade e por tipo de negócio, e escreve uma mensagem de abordagem para cada um, pronta para
enviar pelo WhatsApp. Roda no seu computador.

## Como instalar

Você precisa do [Node.js](https://nodejs.org) (versão LTS), do [Git](https://git-scm.com) e de
uma IA de terminal: Claude Code, Codex ou Gemini CLI.

Abra a IA numa pasta vazia e cole:

```
Clone o repositório https://github.com/VitorioGomes/prospector-ia e siga o roteiro em skill/PROSPECTAR.md.
```

Ela instala, pergunta o que você vende e faz a primeira busca com você.

## O que saber antes

- A busca não pede cadastro nem chave. Na primeira vez, baixa um programa de cerca de 60 MB.
- Para enviar pelo sistema, você conecta um número de WhatsApp: o do seu atendimento ou um chip
  só para isso. Mensagem para quem não conhece o número pode levar o WhatsApp a bloqueá-lo, e um
  chip separado protege o número principal. Envie aos poucos.
- O sistema envia texto, imagem, vídeo, áudio e documento, na hora ou agendado.
- Nada é enviado sem você ler e aprovar.
- Testado em Windows.
